# Download Certificate


A `Certificate` can be downloaded on its own, with its chain, or as a PKCS#12 file that also holds its private key.

## Download a certificate

1. Click **Certificates** in the left menu and open the `Certificate`
2. Click **Download** (download symbol <span style={{color: '#1473b5',}}><span aria-hidden="true">↓</span></span>)
3. For the certificate on its own, select the **Certificate Format**, **Raw** or **PKCS#7**, and the **Certificate Encoding**, **PEM** or **DER**
4. For the certificate with its chain, switch on **Certificate Chain** instead, and select the **Certificate Chain Format** and **Certificate Chain Encoding**
5. Click **Submit**

The file extension follows the format and the encoding:

| Format     | PEM    | DER    |
|------------|--------|--------|
| **Raw**    | `.pem` | `.cer` |
| **PKCS#7** | `.p7c` | `.p7b` |

A raw DER file holds a single certificate, so a chain is downloaded as raw PEM or as PKCS#7.

## Download with the private key as PKCS#12

The **Certificate Format** list offers **PKCS12 – certificate, private key and chain (.p12)** when:

- the `Certificate` is issued, and its `Key` holds the private key that matches it
- that key item is [exportable](../../concept-design/core-components/key.md#exportable), active and enabled; a key is created and imported disabled until you enable it
- the key's `Token Profile` [exports](../../concept-design/core-components/key.md#import-and-export) the key's algorithm, which needs a token created on a Cryptography Provider v2 connector that exports keys, such as the Software Cryptography Provider
- you hold the `exportKey` permission on `keys`, among the [permissions a PKCS#12 download needs](../../concept-design/core-components/key.md#permissions)

To download it:

1. Select **PKCS12 – certificate, private key and chain (.p12)** as the **Certificate Format**
2. Enter the **Password** and **Confirm password**. The password needs at least 12 characters, all printable ASCII, so that every tool, including Java keytool, can open the file.
3. Fill in the provider's export attributes, when it has any
4. Click **Download**

The file holds the private key, as its cryptography provider protected it, the certificate and its [chain](../../concept-design/core-components/certificate.md#certificate-chain), without the self-signed root of a complete chain. It is named after the certificate's common name, with the `.p12` extension. OpenSSL 3.x, Java keytool, and Windows Server 2019 or later open these files. Earlier consumers that need the legacy 3DES and SHA-1 profiles are not supported. The certificate's history records the download as **Download Keystore**.

## Permissions

Downloading a certificate needs the `detail` permission on `certificates`.
