# Text-based user interface

ILM appliance is using Text-based User Interface (TUI) to ease initialization and operations of the appliance.

## Menu overview

| Menu | Purpose | Reference |
|---|---|---|
| Main menu | Common appliance initialization and operation tasks. | [Main menu](./main-menu.md) |
| Advanced menu | Additional appliance administration tasks. | [Advanced menu](./advanced-menu.md) |
| Network menu | Hostname, network, proxy and time configuration. | [Network menu](./network-menu.md) |

Menu labels and available actions can vary by appliance version. The linked pages describe the operations and their effects.

## Keyboard navigation

| Key | Action |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move between menu options. |
| <kbd>Tab</kbd> | Move between input fields and buttons. |
| <kbd>←</kbd> / <kbd>→</kbd> | Move between adjacent buttons. |
| Highlighted letter | Jump to an option. Press again when multiple options share a letter. |
| <kbd>Enter</kbd> | Select the highlighted option. |
