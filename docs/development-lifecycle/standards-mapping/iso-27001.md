# ISO/IEC 27001:2022 Annex A

ISO/IEC 27001 is the international standard for an information security management system. It is applied to, and certified for, an organization rather than a software product, and its Annex A lists the standard's reference set of controls. This page indexes the Annex A controls that bear on how software is developed.
