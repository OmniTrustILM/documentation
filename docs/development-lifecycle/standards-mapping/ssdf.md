# NIST SP 800-218 (SSDF) v1.1

NIST SP 800-218, the Secure Software Development Framework (SSDF), is a set of fundamental secure-development practices published by NIST for producers of software. Version 1.1 groups those practices under four headings: preparing the organization, protecting the software, producing well-secured software, and responding to vulnerabilities. This page indexes each group against the themes below.
