# PCI Software Security Framework, Secure SLC Standard

The PCI Secure SLC Standard is one of two standards in the PCI Software Security Framework, published by the PCI Security Standards Council; the other governs the software itself. Secure SLC instead addresses a software vendor's secure development lifecycle. This page indexes its requirement groups against the themes below.

| Requirement group | Themes |
|---|---|
| Governance and security responsibility | [T1 Documented and applied lifecycle](./overview.md#t1)<br />[T9 Segregation of duties and least privilege](./overview.md#t9)<br />[T15 Accountability for assisted development](./overview.md#t15) |
| Secure software engineering | [T2 Requirements and security criteria before implementation](./overview.md#t2)<br />[T3 Design and analysis before implementation](./overview.md#t3)<br />[T4 Secure coding and code quality](./overview.md#t4)<br />[T5 Independent review before a change is accepted](./overview.md#t5) |
| Security testing | [T6 Automated security verification](./overview.md#t6)<br />[T7 Testing and acceptance](./overview.md#t7) |
| Change management and software integrity | [T8 Change control and traceability](./overview.md#t8)<br />[T12 Build and release integrity](./overview.md#t12) |
| Vulnerability management and stakeholder communication | [T13 Vulnerability handling and disclosure](./overview.md#t13)<br />[T14 Security updates and supported versions](./overview.md#t14) |
