# Introduction

ILM is an open-source platform for trust lifecycle management. It helps you manage certificates, cryptographic keys, secrets and signing services across your infrastructure, with a consistent approach to inventory, access control, integration and automation.

Start with the concepts, connect to an existing installation, or choose how to deploy. You do not need prior platform experience to explore the documentation.

## Trust Lifecycle Components

| Area | What you can explore |
|---|---|
| [Certificates](./certificate-key/concept-design/modules/certificate-management.md) | Discover, issue, renew, distribute and revoke certificates across connected certification authorities and environments. |
| [Cryptographic keys](./certificate-key/concept-design/modules/key-management.md) | Create and manage keys, cryptographic operations and technology providers. |
| [Secrets](./certificate-key/concept-design/modules/secret-management.md) | Store, version and synchronize secrets across vault technologies, using profiles and compliance rules. |
| [Signing with SignServer](./signserver/introduction.mdx) | Configure production signing and validation services across supported formats and technologies. |
| [Native timestamping](./signing/introduction.mdx) | Explore the native signing area and its timestamping preview. |

The [cryptographic asset inventory](./certificate-key/concept-design/modules/cryptographic-asset-inventory.md) combines assets declared by synchronized Cryptographic Bills of Materials (CBOMs). It helps you inspect the cryptography in use and understand each asset's post-quantum readiness verdict.

## Cloud-native Architecture

The platform uses a modular microservice architecture and is designed for Kubernetes deployments. Interfaces connect clients to Core, which applies access control and application logic. Connectors provide consistent interfaces to technology-specific services.
